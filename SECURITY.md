# Security

## Scope

This project processes local JSON files and does not connect to remote hosts.
Do not place real credentials, private hostnames, customer information, or
employer inventory in this repository.

## Reporting

Report a suspected vulnerability privately to the repository owner. Do not
include live credentials or confidential production data in a public issue.

## Safe Testing

Use only the synthetic files under `examples/`. The decommission command
generates a plan and never executes infrastructure changes.
